# Why 0.52.0

The add-account screen is five titles and a chevron. The local demo already shows an icon and one line of what each choice does. That is the screen to ship.

Popup and sidebar share one list. A second density would drift from the demo and from each other.

Watch and combined already have `IconEye` and `IconLayers`, and those paths match the demo. Seed, burner, and import do not, so those three glyphs are new and stay in `StrokeIcon`.

Subtitles are catalog strings so Traditional Chinese, Simplified Chinese, and English stay together. Titles already exist.

Creation flows, the import sub-chooser, and commands stay. This version is the list the user taps, not the forms behind it.

Debug mode settings and the Helius guide sentence are already written as unversioned work. They are not this version.
