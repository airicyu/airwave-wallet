# 0.32.0 — 為何審批模擬不再換 blockhash

審批模擬若帶 `replaceRecentBlockhash: true`，節點會用自己的新 blockhash 算差額。畫面可以一直成功，送出仍用交易裡那個已經失效的 blockhash，preflight 回 `BlockhashNotFound`。

[0.10.0](../../0.10.0/INDEX.md) 當時選換 blockhash，是為了過期交易仍看得到差額。手測證明這會讓模擬與送出不一致。本版讓審批模擬使用送審交易自己的 blockhash：過期時預期變動失敗，使用者在核准前看得到。

不在送出前偷偷換成新 blockhash。那會改掉 dApp 交來的 message，簽出去的不是使用者看到的那筆。

交易費本來就由簽名數與 CU 算出，不是模擬差額。把它掛在模擬回傳上，每次刷新都會重畫交易費。週期模擬只該改預期變動。

查詢中右側只有重新整理。模擬回來才把 Inspector 插在同一側，原本點下去的那個座標變成另一顆圖示。兩顆從第一屏就留在固定位置；還沒有網址就停用 Inspector，不先藏起來。

0.30.0 的懸浮 pill 與置中的標題、置左的站點不在同一條欄線上。單列卡放回標題與預期變動之間，站點改回置中的方角卡。只寫「低」會被看成不安全，所以右側寫「風險指數: 低」。

Home 頂欄已經有底線。簽署頁的帳戶 widget 浮在內容頂上，下面加一條同規格的線，才分得開 widget 與站點。
