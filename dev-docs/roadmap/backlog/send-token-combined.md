# 聚合錢包帳戶送出代幣 — backlog

構想尚未排進某版 INDEX，**不是契約**。排程後以該版 INDEX 為準。

前提是單一可簽送出已於 [0.12.0](../0.12.0/INDEX.md) 出貨。本項不做那條路徑本身。歸集（把其他成員的同一資產先轉到目前錢包）不在本項。

## 現況

Home 對聚合錢包帳戶顯示各成員地址的加總。簽名只對**目前錢包**那一條地址。送出構想在第一版**擋住**聚合：沒有送出入口。可動用餘額若用畫面上的加總，使用者會以為跨成員都能扣。

## 產品意向

目前錢包帳戶是聚合、且目前錢包**可簽**時，能從持倉列進入送出。

- 來源只有目前那條成員地址。可動用數量是這一條名下的餘額，不是該列加總。
- 送出頁寫明來源地址（前 4…後 4）與這一條的可動用數量。超過這一條不能送。
- 切換目前錢包之後，下一次送出改從新的那一條扣（該條須可簽）。
- 目前錢包僅可查看、或簽不了：不提供送出。
- 資產種類、收款、確認、組交易與 `sendTransaction` 沿用已出貨的送出；不另開一套。

唯讀成員上的數量留在鏈上。本項不把其他可簽成員拼進同一筆，也不先歸集再送。

## 開工前仍須拍板（排進 INDEX 時）

- 入口與單一帳戶同一套，或聚合列要多一句「從目前地址送出」。
- 送出頁要不要列出其他成員這項資產的數量（只讀，不能拿來加進可動用）。
- 送出進行中切換目前錢包：這筆仍簽開始時凍結的那條地址。

## 非目標（構想層）

- 歸集、或多簽把多名成員湊成一筆
- 可動用等於 Home 加總
- 從僅可查看的成員扣
- 對 dApp 宣告 `signAndSendTransaction`
