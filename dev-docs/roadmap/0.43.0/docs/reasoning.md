# 0.43.0 — 為何這樣定

## 入口在漢堡選單

曾考慮放 Settings。使用者要它緊接「錢包帳戶」，因為這是常用名單，不是設定項。Settings 不再放第二入口，避免兩套管理。

## 名稱後的鉛筆

帳戶列表改名已是名稱後面的 `IconRename`。Address cards 用同一顆，避免兩種鉛筆。點了只換同一行的文字，不開第二塊表單：一筆只有名稱可改，地址要換就刪了再加，所以沒有需要展開的欄位。

## 全螢幕兩個分頁

半屏抽屜在 600px popup 裡塞不下兩組，也會壓住送出表單。全螢幕返回即放棄挑選。

兩組不併成一張清單：錢包帳戶是自己的戶（含唯讀與聚合的目前錢包），Address cards 是記下來的別人。分頁讓使用者知道自己在選哪一種。聚合不展開全部成員，因為送出簽名規則仍是「目前錢包」；成員地址若要當收款人，用 Address cards 或手貼。

錢包列不寫「可簽」「唯讀」：帳戶列表已經用顏色圖示表達，再寫字是重複。

## 不升 schema 世代

新鍵與既有 `accounts`／`vault` 無關。0.26.0 的世代只在改那些 v1 形狀時遞增。本版缺鍵即空陣列，舊安裝不用遷移步驟。

## 白名單不擋手貼

擋掉名單外地址會把送出變成允許清單，超出構想，也讓空名單無法送出。挑選只是填字。
