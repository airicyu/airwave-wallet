變更錢包密碼

非正式契約，與 generate-wallet-ux.html、settings-rpc-ux.html 同級。衝突時以以後版 INDEX 為準。 示範可在左側架內自行輸入；本稿不寫死真實密碼字串。

互動說明

Settings 主頁仍放 RPC／Helius；「錢包密碼」只是一列入口，三欄表單在子頁。殼底主按鈕提交，失焦不寫金庫。

  • 空表單：三欄皆空，變更密碼 disabled。
  • 可提交：三欄齊、新密碼達最短長度且兩次相同；點主按鈕才送（本稿只模擬）。
  • 不一致：短錯誤，不送 command。
  • 舊密碼錯：短錯誤，金庫不變（本稿以內部旗標模擬，畫面不展示對照字串）。
  • 成功：短句＋toast，欄位清空；可 Back 回 Settings。

建議開工前拍板（不是 INDEX）

  1. 新密碼最短長度：沿用建庫 8 字元。同一把錢包密碼，建立與變更不該兩套門檻。不足 8 字時主按鈕 disabled，不另寫欄位 hint。
  2. 鎖定時不能改密；必須先解鎖。現行 Settings 在鎖定時本來就進解鎖頁，改密不該成為繞過 session 的旁路。已鎖定帽只見解鎖，看不到這列與子頁。
  3. 密碼不得進 Google：不要 type="password"，也不要 current-password／new-password。用 type="text" + -webkit-text-security: disc，並套抗管理器屬性。建庫／解鎖／Reveal 必須同一套，否則安裝當下仍會被問。代價：不能靠 Google 一鍵填錢包密碼。

建議其餘取捨

  • 主按鈕文案：變更密碼（對齊動作本身；不要「儲存」以免與失焦 auto-save 設定頁混淆）。
  • 不要眼睛圖示。打碼靠 -webkit-text-security，不是 type="password"。
  • Back 清空三欄與錯誤／成功句，避免秘密留在 DOM。
  • 沒有「忘記密碼」。畫面不教使用者「不要忘記」。
