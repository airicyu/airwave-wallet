Add-account chooser

Informal concept for the extension popup and sidebar. Five rows: stroke icon, title, one-line subtitle. Navigation stays the same as today. Not a contract.

新增帳戶

Rows

  • 建立助記詞錢包 — 產生新的 12 詞助記詞（pin）
  • 建立拋棄式錢包 — 本機暫用，不長期保管（flame）
  • 匯入錢包 — 助記詞或密鑰（download）
  • 建立觀察帳戶 — 只讀地址，無法簽名（eye）
  • 建立聚合錢包帳戶 — 合併多帳戶資產視圖（stacked cards）

Frame is the extension popup width (384px), not a phone shell. Subtitles are the Traditional Chinese copy for this concept.
