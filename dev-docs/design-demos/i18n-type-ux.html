字體與語言

概念稿，產品還沒改。字體請在三組裡選一組。語言設定沿用現在的「網路」單選列：點了立刻換，沒有儲存鈕。

畫面寬 422px（現在 popup 的寬）。金額、地址維持等寬字，不跟著 UI 字體走。專有名詞不翻譯：Devnet、RPC、SOL、API keys、Default CU price、Airwave。

請拍板
  • 字體已選 B 系統雙字：英文 Segoe UI，中文（繁簡同一套）微軟正黑體 UI。Mac 落到蘋方 TC。
  • 中文標題字距改 0。現況解鎖標題的 0.02em 會把漢字拉開。
  • 設定樞紐第一列是語言。列名跟著介面語言；右邊摘要永遠寫該語言自己的名字（繁體中文／简体中文／English）。
  • 語言頁是三列單選，版式對齊網路頁。不用頂部分段——三個語言名字在 422px 裡會擠，也和「網路」的選法不一致。
  • 預設語言固定繁體中文。不跟瀏覽器語言走。

1. 選字體

三個 popup 是同一畫面。切到简体中文時，B 與 C 的中文字體不變。帳戶名「日常」是使用者自訂的，不翻譯，用來看中英混排。

A · 現況

只寫 Segoe UI。漢字靠 Windows 自己去連字，連到哪套不固定。標題還留著 0.02em 字距。

B · 系統雙字已選

英文 Segoe UI、中文微軟正黑體 UI。繁簡同一套，不切雅黑。Mac 落到蘋方 TC。不打包字型。標題字距 0。

C · Inter + Noto

英文 Inter、中文 Noto Sans TC。繁簡同一套。粗細有 600，中英最齊。字型檔大，帳戶名仍要系統字後備。

這頁在做什麼

  • 語言名字不跟著介面翻。介面若已是 English，你仍看得到「繁體中文」。
  • 沒有說明句、沒有儲存。和網路頁一樣，選了就寫進設定。
  • 解鎖頁、簽署頁、popup 讀同一組語言。本稿只畫設定入口；三語文案長度以 422px 單行為準，放不下就省略號，全文放在 title。
  • 預設提案是固定繁體中文。若要改成「瀏覽器是簡中或英文就跟著，其餘落繁中」，直接說。
