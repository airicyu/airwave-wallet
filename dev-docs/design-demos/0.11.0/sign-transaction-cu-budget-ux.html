畫面意圖

非正式交易費獨立一卡。總費是簽名費加優先費。

  • 主舞台仍是 phase 2 預期變動。沒有「會成功」。
  • 總費永遠可見。簽名費／優先費／CU 收在預設關的明細。
  • 配對右側一顆狀態圖示：已套用為淡勾；任一欄相對上次提交變 dirty 則變待確認。點擊才同時套用兩欄、更新 ix、重模擬。不是逐鍵 debounce。
  • dirty 或超出範圍時批准停用；確認成功後圖示再變淡，批准才可點。
  • 已簽名：三筆費用與 CU 皆唯讀，圖示淡化。批准不改 instruction。
  • Settings「Default CU price」，出廠 25000。

計算（本稿 JS）

優先費 lamports = ceil(limit × price / 1e6)，與鏈上進位相同。簽名費示範 5,000 lamports（一個簽名）。總費＝兩者相加。
