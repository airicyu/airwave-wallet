實作備註

  • 安裝後先設密碼並建立保險庫。產生／匯入／觀察不再出現密碼欄，也不把「尚無保險庫」當成路徑。
  • 助記詞匯入是概念，尚未實作。產品今日僅有密鑰匯入。不要在 popup 內放紅條說明，除非該能力上線後的空狀態。
  • 助記詞分兩屏：先填 12／24 詞（殼底「下一步」）；再選路徑方案並從衍生列挑一戶（殼底「匯入」）。不要在同一屏混填 path + 單一 index。
  • 方案短標：標準＝m/44'/501'/{n}'/0'（Phantom／Solflare）；CLI／Ledger＝m/44'/501'/{n}'；Change＝m/44'/501'/0'/{n}'；自訂須含 {n} 或 n' 佔位。列出 index 0–19，列上只顯示 #n＋公鑰前4…後4＋SOL（nowrap）；完整 path 單行 ellipsis 放方案下方。
  • 密鑰欄一次貼上即可：偵測 [193, 240, …] JSON／位元組陣列，或 base58 secret。狀態列只顯示「base58／位元組／無法辨識」。
  • Combined：可貼多行、或單列＋加號圖示。第一個有效地址＝目前錢包，使用者可點 chip 改選。勾選既有帳戶立刻加入成員。頁級主按鈕在殼底 flex-shrink:0 停靠列。
