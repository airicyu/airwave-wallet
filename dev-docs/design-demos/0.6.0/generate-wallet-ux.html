產生錢包 — 兩條路徑

非正式契約。現行「產生新錢包」只有 Burner（隨機密鑰、成功只見短地址）。本稿把 Add 拆成新錢包（一次看 12 詞）與 Burner（不看助記詞，之後仍可 Reveal 密鑰）。示範詞為虛構，不是 BIP39。

新增帳戶

設計審查

對照現況：Add 一項「產生新錢包」→ 名稱 → 產生 → 短地址。使用者若要可恢復錢包，會以為已經有助記詞，其實沒有。

拆成兩項，不要藏在第二層

一屏一件事。Add 列表直接兩條，對齊「建立觀察帳戶」句式：建立助記詞錢包、建立 Burner 錢包。不要在按鈕下寫教學句。

助記詞錢包

  1. 單屏：名稱選填＋12 詞（每列 3）＋地址。
  2. 進入頁即產生詞（尚未寫 vault）。殼底「建立」才寫入 phantom index 0。
  3. Back 放棄、不建檔。關 popup 清詞。

不考三個詞、不存助記詞、不 log。之後 Reveal 只出私鑰，不再出這 12 詞。

Burner

維持現況：隨機 Keypair、不衍生 HD、不顯示助記詞。成功只見地址。Manage 仍可 Reveal。適合丟棄用。

不做

  • 產生 24 詞、passphrase、備份 quiz
  • 把助記詞寫進 storage
