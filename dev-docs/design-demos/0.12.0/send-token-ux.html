送出代幣

非正式契約。點持倉列進入代幣詳情。名稱下方的「送出」才進填寫。確認後打開現有簽署交易審批，不另做一頁。

Popup 384×640

畫面意圖

非正式持倉列版面不改。點列是看詳情，不是送出。

  • 整張持倉卡進入詳情：圖示、名稱、mint、數量、verified、Jupiter score。原生 SOL 的 mint 寫「原生」。
  • 「送出」在代幣名稱下方：圖示加文字、有外框，寬度只包住內容。只有單一可簽帳戶有這顆。聚合、觀察可看詳情，沒有送出。
  • 送出頁只填數量與收款地址。確認後組的是一般轉帳，打開現有簽署交易 popout：預期變動、交易費卡，以及預設收合的交易明細（每條指令的帳戶縮寫與 data hex）。不另做審批頁。
  • 批准後由錢包送出。該表面轉圈直到 confirmed，再等 500ms。Popout 關窗。Popup 回主畫面。日後 sidebar 也回主畫面。
  • dApp 叫來的 signTransaction 仍只簽名交回，不由錢包再廣播。等 confirmed 用在錢包自己送出的交易。
  • wSOL 當代幣送，不先 unwrap。地址簿未排，不留空圖示。

本稿數字

SOL 餘額 1.25、簽名費 5,000 lamports。確認中在本稿約 1 秒後回主畫面，正式版要等鏈上 confirmed 再加 500ms。地址與 mint 為假資料。
