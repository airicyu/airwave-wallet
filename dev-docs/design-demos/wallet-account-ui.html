管理

  • 「主錢包」在小卡外面、小卡上方。小卡只放名稱、地址、複製。
  • 成員自含一塊。握把之後是圓形勾：主錢包高亮完整勾，其餘淡勾，滑過稍亮。刪除在最右，和前一顆隔開。右側圖示 28px。滑過整列只把底色稍為變淺。拖曳只從握把開始。加號在標題列右上。Imported 1 對到本機帳戶，沒有鉛筆。另外兩列的鉛筆進入改名子畫面，名稱可以留空。

加入成員

  • 兩個選項：新地址、本機帳戶。
  • 新地址是再下一層，只有輸入與底欄加入。
  • 本機帳戶才列出全部本機錢包：已加入只標狀態，尚未加入才有加號。
