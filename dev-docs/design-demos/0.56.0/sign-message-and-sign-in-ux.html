簽署訊息與登入

非正式概念稿。三個畫面共用同一殼：凍結帳戶、站點列、一張文字卡、拒絕／批准。 示範 https://swap.app、7xKX…gAsU。

Popout 384×600

畫面意圖

非正式帳戶在左上，與簽署訊息 popout 同一套 widget。站點是內容第一行。視窗標題在主區正中。

Off-chain message

  • 視窗標題是 Sign message，與今天的簽署訊息視窗相同。
  • 主體只有一張 UTF-8 文字卡，標籤沿用可讀 signMessage 的 Message payload。
  • 可讀的 raw signMessage 與 off-chain message 長得一樣。使用者不用分辨這兩個功能，畫面上沒有格式切換。
  • 沒有第四個 useOffchainMessage 畫面。off-chain 包裝不改變這個畫面；站點旗標只在批准之後改變要簽的位元組。
  • 沒有 hex 區塊、警告、簽名者清單。

Sign in, short / Sign in, full

  • 視窗標題改為 Sign in。殼不變：同一站點、凍結的同一帳戶。
  • 主體是同一張 Message payload，內容就是即將簽下去的 SIWS 原文。沒送的欄位整行不出現。
  • 短版只有固定句和地址。完整版接上 statement、URI、Version、Nonce、Issued At。
  • useOffchainMessage 不改變這個畫面。
  • 底欄是拒絕與批准。
