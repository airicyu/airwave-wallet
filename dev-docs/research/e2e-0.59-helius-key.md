# e2e after the 0.59.0 Helius API key

Engineering note, not a version contract. Written 2026-11-13. This does not change `wallet/src`. It is the brief for a later edit of the e2e playbooks.

## What the wallet does now

The Helius settings field stores an API key. A pasted URL is kept only long enough to read an `api-key` or `apiKey` query. The stored value is the key.

Mainnet Activity always calls `https://api.helius.xyz/v0/addresses/{owner}/transactions` and sends that key as `api-key`. Private balance RPC always uses `devnet.helius-rpc.com` or `mainnet.helius-rpc.com` with the same key. Neither call reads a user-configured Helius host.

Debug mode still overrides only the Jupiter API URL and the OpenRouter base URL. There is no Helius origin field.

## Settings the playbooks should name

Debug stays on. Jupiter, OpenRouter, and the Mainnet blockhash probe stay at `http://127.0.0.1:8787`. Devnet RPC stays at `http://127.0.0.1:8899`. The default priority fee stays `5000`. The Helius field is an API key. Do not tell the runner to set a Helius API URL to `http://127.0.0.1:8787`. That value is not used as a host, so Activity will not reach the mock.
