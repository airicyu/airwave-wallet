# 錢包地址簿 — backlog

構想尚未排進某版 INDEX，**不是契約**。排程後以該版 INDEX 為準。

與 [send-token.md](./send-token.md) 相關：送出時代幣時，收款人可以從這裡選。地址簿可以單獨先做；送出頁尚未存在時，本項仍是一份可維護的白名單。

## 現況

沒有地址簿，也沒有可持久化的收款白名單。持倉列表不能送出代幣。使用者若要記一條常用地址，只能記在擴充外面。

## 產品意向

使用者維護一份**地址簿**：每一筆是顯示名稱＋一條 Solana 地址。這份清單就是送出時可選的收款白名單。

- 可新增、改名稱、刪除。地址要是有效的 base58 公鑰；名稱空白不能存。
- 同一條地址不重複。名稱可改，不強制唯一。
- 存進 `chrome.storage`（使用者資料，不是金庫秘密）。重新開啟後還在。不放私鑰、助記詞或密碼。
- 名單不依 cluster 拆兩份：同一條地址在 mainnet 與 devnet 都可被選；實際餘額仍看送出當下的 cluster。

送出代幣時（見送出構想）：收款欄可以改為從地址簿挑一筆，挑了就填入該地址當 recipient。仍可改回手動貼上，白名單**不是**唯一允許的收款人。沒有任何一筆時，送出頁不阻塞，只是沒有可選項。

管理入口在主畫面裡找得到（Settings 或送出流程裡的「管理地址」；排進 INDEX 時定一處）。刪除只影響名單，不影響鏈上帳戶，也不改已送出的交易。

讀寫經 service worker command。popup 只渲染。不把名單放在 pending，也不靠 UI 自己寫 storage 當另一條真相。

## 開工前仍須拍板（排進 INDEX 時）

- 管理頁放在 Settings，或只從送出頁進出。
- 一筆除了名稱與地址，要不要備註。
- 名單很長時要不要搜尋。
- 從自己的錢包帳戶列表「加進地址簿」算不算本項（本構想預設只手動加地址）。

## 非目標（構想層）

- 只允許轉給白名單、擋下其他地址
- 匯入整份聯絡人檔、鏈上域名（SNS）解析
- 替地址簿的地址代簽、或把對方的密鑰存進來
- 依 cluster 各存一份名單
