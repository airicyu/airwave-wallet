# 解鎖畫面預設聚焦密碼欄 — backlog

構想尚未排進某版 INDEX，**不是契約**。排程後以該版 INDEX 為準。

## 產品意向

解鎖畫面一顯示，焦點就在密碼欄，使用者不用先點欄位就能打密碼。

涵蓋每一處解鎖畫面，同一規則：

- Popup 鎖定殼：`#locked` 裡的 `#unlock-password`
- 簽署／連線 popout 的解鎖畫面：`#unlock-password`
- Popup 內審批宿主的解鎖畫面：`#appr-unlock-password`

只在這張畫面**變成可見**時聚焦。之後使用者自己點到別處，不要因為狀態刷新再把焦點搶回去。密碼送出失敗、畫面仍是解鎖時，焦點回到密碼欄。

## 非目標（構想層）

- 首次建立密碼、變更密碼、其它密碼欄
- 自動填入或記住密碼
- 改解鎖文案、版面、送出行為
