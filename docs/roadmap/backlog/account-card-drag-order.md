# 帳戶卡片拖曳排序 — backlog

構想尚未排進某版 INDEX，**不是契約**。排程後以該版 INDEX 為準。

## 產品意向

Accounts 列表裡，**wallet account card 最大的那一塊**（現有 `.account-card-main`：名稱、徽章、縮寫地址；不含列尾 kebab、重新命名、複製）是**拖曳把手**，用來拉帳戶次序。

畫面不要寫「可拖曳排序」。提示只靠這塊區域：

- **滑鼠懸停：** 出現陰影，並顯示一區虛線點點（grip），讓人知道這裡抓得起來。
- **游標：** 懸停為可拖曳（`grab`）；按住拖移時為 `grabbing`。
- 重新命名、複製、kebab **不**啟動拖曳，點下去仍是原動作。

短按這塊區域仍沿用現況：設為 active 並回到 Home。指標位移超過門檻才算拖曳；拖曳結束**不**觸發切換帳戶。

放下後次序立刻寫入 `airwave.accounts.v1` 的陣列順序（service worker command）。只改順序，不改 `id`、公鑰、金庫、連線。Active 不會因為被拖過而換人。重新整理後次序還在。

單一錢包與 Combined 都在同一條列表裡排，沒有另一套順序。

## 開工前仍須拍板（排進 INDEX 時）

- 虛線點點是懸停才出現，或平時就有很淡的一列、懸停再加陰影。
- 拖曳門檻（像素）與放下時的插入線長什麼樣。
- 鍵盤能否調整次序（本構想只定滑鼠）。

## 非目標（構想層）

- 用一句說明文字教使用者拖曳
- 拖 Home 代幣列、拖 Combined 成員
- 另做「上移／下移」文字按鈕當主路徑
