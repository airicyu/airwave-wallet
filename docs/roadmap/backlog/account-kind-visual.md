# 錢包帳戶類型圖示 — backlog

構想尚未排進某版 INDEX，**不是契約**。排程後以該版 INDEX 為準。用語依 [`docs/DOMAIN.md`](../../DOMAIN.md)。

## 產品意向

錢包帳戶列在畫面上分成三種，各用**一個圖示**，而且**每種一種圖、一種顏色**。掃過去就分得出來，不靠讀文字徽章。

| 畫面類型 | 對應資料 | 圖示 |
|----------|----------|------|
| 單一錢包帳戶（簽名錢包） | `kind` 缺省或 `"signing"`，金庫有該 id 的密鑰 | 一種圖、一種色 |
| 單一錢包帳戶（唯讀錢包） | `kind: "readOnly"` | 另一種圖、另一種色 |
| 聚合錢包帳戶 | `kind: "combined"` | 再另一種圖、再另一種色 |

儲存仍然只有單一與聚合兩種列。唯讀不是第三種錢包帳戶，只是單一列沒有金庫密鑰；圖示把它和可簽的單一列分開。鎖定時圖示不改：唯讀看列上的 `kind`，不看目前有沒有解鎖。

兩處用**同一套**圖示與顏色：

- **錢包帳戶 widget**（Home 頂欄 pill 的 `WalletWidget`，以及簽署殼頂欄同一套 widget）：細微，小圖示即可。名稱、複製對外公鑰、點進 Accounts 的行為不變。
- **Accounts 列表**（`#accounts-list` 的帳戶卡片）：同一圖、同一色，尺寸夠掃到。

現況的文字徽章（`accounts.badgeCombined`、`accounts.badgeReadOnly`）由這顆類型圖示取代，不要圖示旁邊再掛同一句種類徽章。作用中帳戶的「使用中」標記仍留。`title`／`aria-label` 用類型名稱，走 `ui-messages` catalog，跟目前 `settings.locale`。

圖示是現有 stroke SVG 風格。顏色用三種彼此分得開的色，跟「使用中」的 accent 不要撞成同一含義。

## 開工前仍須拍板（排進 INDEX 時）

- 三種各用哪一個圖、哪一個色。
- Widget 的小圖是放在現有字母頭像上，還是取代頭像。
