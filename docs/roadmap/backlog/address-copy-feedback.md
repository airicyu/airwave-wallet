# 地址複製回饋 — backlog

構想尚未排進某版 INDEX，**不是契約**。排程後以該版 INDEX 為準。

## 產品意向

錢包殼頂欄、帳戶 widget 旁的**地址複製圖示按鈕**，點下去成功寫入剪貼簿之後，要有一段短暫、看得到的回饋，讓人知道地址已經複製。現況只呼叫 `navigator.clipboard.writeText`，圖示與無障礙名稱都不變，使用者無法分辨有沒有複製成功。

範圍是這顆圖示鈕，兩處同一顆：

- popup 頂欄 `#btn-widget-copy`（複製目前 active 帳戶對外公鑰）
- popout 簽署頂欄 `#btn-copy-pk`（複製該次簽署帳戶公鑰）

回饋出現在**按鈕本身**（例如圖示短暫換成勾，或同等的「已複製」狀態），幾秒內回到原本的複製圖示。複製失敗時不要顯示成功回饋。

## 開工前仍須拍板（排進 INDEX 時）

- 成功狀態的具體樣子：換成勾、改 `title`／`aria-label` 為「已複製」、或兩者都做。
- 成功狀態維持多久再還原。
- 剪貼簿被拒時要不要在按鈕上顯示失敗（本構想只要求成功才給已複製回饋）。

## 非目標（構想層）

- 帳戶卡片、mint、助記詞、私鑰等其他複製鈕
- 另開 toast、snackbar 或全螢幕提示當主回饋
- 改複製的內容（仍是該帳戶對外公鑰）
