| [DOMAIN.md](./DOMAIN.md) | 跨版領域用語。寫 INDEX、HOW、註解、UI 時以它為準；該版 INDEX 明文覆寫時以 INDEX 為準並回寫本檔 |

| [research/](./research/) | 工程筆記，不是某版契約：[secret-field-autofill.md](./research/secret-field-autofill.md)、[extension-message-flow.html](./research/extension-message-flow.html) |
| [design-demos/](./design-demos/) | 非正式 HTML 概念稿。與 INDEX 衝突時以 INDEX 為準 |
| [brainstorm/](./brainstorm/full-picture.md) | 重做前的方向與教訓，**不是**某版契約。與 INDEX 衝突時以 INDEX 為準 |
