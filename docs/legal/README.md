# Legal copy

The wallet hamburger menu **About this app** loads these Markdown files directly (embedded at build time):

| File | Screen |
|------|--------|
| [disclaimer.md](./disclaimer.md) | Disclaimer |
| [terms-of-use.md](./terms-of-use.md) | Terms of use |
| [privacy-policy.md](./privacy-policy.md) | Privacy policy |

The Chrome Web Store Privacy Policy URL must be a page that **opens without a login**. Once this repo is public, the blob URL of that file on GitHub can be used. If review requires a standalone site, switch it to GitHub Pages or your own domain.

This is defensive copy shown to users inside the product. It is not a legal opinion from a lawyer, and it is not the code license. The code license is the [Apache License 2.0](../../LICENSE) at the repo root. Governing law is written as "the developer's jurisdiction." If the text needs to be enforceable in a specific place, a lawyer should revise it and these files should be replaced.
