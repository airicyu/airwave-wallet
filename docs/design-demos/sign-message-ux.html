簽署訊息 popout

非正式契約。UTF-8 通過則先顯示文字卡，其下永遠有 Hex 卡可複製；否則只顯示 Hex。 示範 https://drip.example.test、4aF1…pda4。

Popout 384×600

畫面意圖

非正式帳戶在左上，與 Home 同一套 widget。站點是內容第一行，不是仿輸入列。

  • 頂欄左：帳戶 widget（名稱在上、地址在下）。popout 裡不當切換器，只標明將簽名的帳戶。
  • 主區最上中央是「簽署訊息」，再來才是站點。
  • 主體用一般卡；副呈現才用展開列、預設收合。
  • 可讀 UTF-8：主體 Message payload 文字卡；副 Raw binary payload 預設收合。
  • 非 UTF-8：主體就是 Raw binary payload 一般卡（不展開）。沒有第二份 payload。
  • 鎖定：整頁一般解鎖；「解鎖」在密碼欄正下方（內容區），殼底隱藏。解鎖後才出現拒絕／批准。批准在解鎖後約 0.7 秒內 disabled，避免連點打到同一熱區。
