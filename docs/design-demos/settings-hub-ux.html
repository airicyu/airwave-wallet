Settings 樞紐

非正式契約。Settings 第一層只列入口，秘密不進列表。衝突時以以後版 INDEX 為準。 示範用虛構字 https://example.test/?api-key=demo、demo-not-a-real-key；預設遮罩帽不把全文放進可見 DOM。

畫面意圖

四列 submenu。網路是兩列單選（現在用哪個 cluster）；RPC 是兩張卡分別編 Devnet／Mainnet 清單。不要用分段 tab 來選網路。

  • 網路 — 兩列：Devnet、Mainnet；圓點表示目前選中；點了立刻切換
  • RPC — 上卡 Devnet、下卡 Mainnet；各有 radio 清單。目前 cluster 的那張卡標「目前」
  • API keys — Helius URL ＋ Jupiter key
  • 錢包密碼 — vault。子頁見 change-wallet-password-ux.html

建議寫入時機（不是 INDEX）

  • cluster、RPC 選／加／刪：立刻。
  • Helius、Jupiter：失焦或列內確認圖示。正在打字不算。畫面不教這句。
  • 清除：點刪除圖示，立刻寫成空字串。
  • 變更錢包密碼：殼底「變更密碼」，非 auto-save。
  • 沒有整頁「儲存設定」。

建議API keys（不是 INDEX）

  • 空：空狀態＋可貼上的 type="text"。確認圖示提交該列。
  • 有值：遮罩列＋Reveal 圖示（click toggle，不要錢包密碼）＋編輯／清除圖示。不要第二顆眼睛。
  • 標籤：Helius API URL、Jupiter API key（不要只寫 Helius，以免只貼 key）。
  • 已設定：兩欄都顯示 ••••••。Reveal 才給全文（單行 ellipsis）。不要「已設定」、不要露出後 4 或 ?api-key=。
  • 不要 type="password"（類 C）。錢包密碼列才用遮罩 text（類 B）。
