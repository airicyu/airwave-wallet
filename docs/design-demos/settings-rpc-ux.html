旁邊說明

  • 頂部分段控制才是切換錢包作用中網路（Devnet 或 Mainnet，一次一條）。切換後，下方分頁會跟著對齊到該鏈清單，讓你立刻看到「此刻在用」的 RPC。
  • Devnet 清單 | Mainnet 清單分頁用來編輯對應鏈的端點。點另一個分頁不會改作用中網路，僅能編輯離線清單；黃字提示會寫明「正在編輯非目前網路」。
  • 每條鏈永遠有一筆內建公開 RPC（不可刪、不可當自訂編輯）。自訂端點用 + 加入、垃圾桶刪除；圖示帶 title tooltip，不用文字按鈕。
  • 列高固定一行：radio + 單行省略 URL。點 URL 列才展開完整輸入。內建項展開為唯讀全文。
  • 選取 RPC（radio）、新增、刪除在 demo 裡即時生效；Helius／Jupiter／作用中網路需按底部「儲存」才標記為已提交。
  • 假資料僅用 https://example-rpc.test/…，不含真實金鑰。
